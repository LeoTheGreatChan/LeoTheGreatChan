# Leo Chan

**Product & Data leader with a production-deployed technical portfolio.**

Across three production-deployed builds, a sentiment intelligence pipeline, a predictive operations analytics engine, and a multi-agent complaint triage orchestrator, the same operating pattern repeats. I identify a real operational problem, design a workflow where AI and deterministic logic each do the job they're best suited to, build and ship the automation myself, and deliberately control where AI is trusted versus where control stays in code. Every build is tested, verified against real data, and measured for outcome before I call it done. The result is automation a technical stakeholder can question and trust, not a black box.
